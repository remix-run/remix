Fix missed file changes after a parent directory leaves the watched module graph while a directory inside it is still in use. This happened after hot updates and restarts, for example when the asset server stopped watching a project's `package.json` or `tsconfig.json`. Edits inside the nested directory were ignored, or caused an unexpected full restart once the parent was watched again. With polling, the default on Windows, they could stay ignored until the dev server was restarted. Watched directories now stay watched for the life of the runner, and changes to files outside the current module graph are still ignored.
