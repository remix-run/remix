`run()` now uses a default browser frame resolver when `resolveFrame` is omitted. The default fetches the frame source with `Accept: text/html`, forwards the submitted method, uses `URLSearchParams` for `application/x-www-form-urlencoded` submissions and `FormData` for other non-GET submissions, and supports cancellation with the provided abort signal. Apps only need a custom resolver for behavior such as additional request headers, other body encodings, redirects, or custom error presentation. Set `resolveFrame: false` to disable link and form navigation interception; manual frame reloads then reject because frame resolution is disabled.
