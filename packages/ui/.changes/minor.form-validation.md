Use one form schema from `remix/data-schema/form` for submission parsing and native controls (see #11630). `form.Context` supplies stable typed field bindings that pass through ordinary component props; `root`, `control`, `label`, and `error` mixins provide constraints, validity, and accessible associations while applications own markup.

Context consumes failed `schema.parseSafe()` results directly from `remix/data-schema/form`, which owns restoration, grouped messages, and password/file omission. The render prop always supplies `errors`, with `errors.form` absent when there are no form-level messages. Live errors appear after blur or blocked submission; server errors appear immediately. Shared field error maps, supplemental `setCustomErrors()`, native reset, and new submissions update feedback without setup factories or subscriptions.
