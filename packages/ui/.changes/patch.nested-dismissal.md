Escape and outside clicks now dismiss only the topmost popover or dialog. Holding Escape does not dismiss successive layers. Nested menus preserve the parent when a child popup consumes the interaction, keyboard input inside a nested popup no longer activates the parent menu, and Tab from a menu respects the containing dialog's focus boundary. Popups anchored inside a dialog retain focus access and close with their owner even when rendered elsewhere in the document or after their trigger is removed. Closing an ancestor also releases nested overlays and their scroll locks.
