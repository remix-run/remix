Send the same frame-request headers from the default browser resolver as server-side `render()` middleware. Named and unnamed `<Frame>` requests send `X-Remix-Frame: true` and `X-Remix-Top-Frame-Src`; named frames also send `X-Remix-Target`. Top-frame navigations omit these headers to request a full document. Custom resolvers receive `isTopFrame` and `topFrameSrc` in `ResolveFrameOptions`, so an unnamed frame can be distinguished from the top frame.
