Migration directories accept prefixes of 1 to 64 digits. Use zero-padded sequences such as `0001_create_users` for short names, or `YYYYMMDDHHmmss` timestamps such as `20260228090000_create_users` to record creation time and sort chronologically (`20260228090000` represents `2026-02-28 09:00:00`). `loadMigrations()` requires every prefix in the same migration directory to have the same number of digits so string sorting preserves numeric order (for example `0001`, `0002`, `0010`).
