Fixed an infinite loop (denial of service) in the multipart boundary search. A boundary of 252 or more characters produced a search needle whose length wrapped the `Uint8Array` skip table default to zero, so the search never advanced and looped forever on runtimes that use the JavaScript search path (Bun, Deno, and browsers; Node.js was unaffected because it uses the native `Buffer.indexOf`). The skip table now uses `Uint32Array`, which cannot wrap for any possible pattern length. See GHSA-hpwp-7w8r-373j.
