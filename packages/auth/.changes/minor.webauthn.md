Sign users in with passkeys using `createWebAuthnProvider()`. `startWebAuthnRegistration()` and `startWebAuthnAuthentication()` store a one-time challenge in the session and return JSON options for `navigator.credentials`. `finishWebAuthnRegistration()` and `finishWebAuthnAuthentication()` verify the browser's response against that challenge, the allowed origins, the rpId, and the credential signature, and return a JSON-serializable credential for your app to store. ES256, Ed25519, and RS256 credentials are supported without third-party dependencies, and attestation statements are not verified.

The new `@remix-run/auth/webauthn-client` entrypoint provides `createPasskey()` and `getPasskey()`, which convert those options and the browser's responses between JSON and the binary values `navigator.credentials` uses.
