Validate native form submissions with `remix/data-schema/form` (see #11630). `object`, `text`, `password`, `number`, and `checkbox` describe form decoding while reusing ordinary scalar schemas, checks, and transforms. Form schemas expose `parse` / `parseSafe` methods with equivalent functional APIs. Safe parsing preserves success/value/issues and extends failures with raw restorable values and grouped errors, omitting passwords, files, and arbitrary issue metadata. Core `s.parseSafe` keeps its existing contract. Readonly entries expose original schemas and form kinds to UI adapters. Missing and blank text/number entries reach the supplied schema as `undefined`; checkboxes decode by presence. The existing `form-data` export retains its extraction semantics.

FormData object parsing also retains reserved logical keys such as `__proto__` as ordinary own properties.
