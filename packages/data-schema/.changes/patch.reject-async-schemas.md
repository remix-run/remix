`parse()` and `parseSafe()` now throw a `TypeError` when given a Standard Schema that validates asynchronously, such as a Zod or Valibot schema with an async refinement. Previously, the returned promise was treated as a successful result, so `parse()` returned `undefined`, `parseSafe()` reported success, and any validation issues were ignored. If the abandoned async validation later rejects, the rejection is now handled instead of surfacing as an unhandled rejection, which crashes Node by default.
