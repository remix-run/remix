`staticFiles()` makes fewer filesystem calls for requests that aren't for files. In front of an app's routes it sees every `GET` and `HEAD` request, pages included, and each call waits its turn in Node's small threadpool, so under load the calls slowed every page. A path that isn't a file is now passed on after one call instead of two. With `index: false` and no `listFiles`, a directory's path, such as `/`, is passed on without any, since there's nothing it could serve. Requests for files make the same calls as before, including the check that the file is inside the root.
