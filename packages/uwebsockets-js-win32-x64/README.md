# uwebsockets-js-win32-x64

Native uWebSockets.js payload for win32-x64. Installed automatically through `remix/node-serve`; applications normally do not need to install this package directly.

Contains the unmodified upstream loader, ESM wrapper, types, and binaries for Node ABIs 115, 127, 137, and 141. See [upstream.json](https://github.com/remix-run/remix/blob/main/packages/uwebsockets-js-win32-x64/upstream.json) for the pinned source.
