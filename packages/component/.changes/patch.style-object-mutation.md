Fix element props that receive an object mutated in place. Changing a property on a `style` object, or pushing to an array passed to an attribute like `data-ids={ids}`, and then calling `handle.update()` used to leave the element unchanged, because the runtime skipped any prop that was the same object as in the previous render. The element now picks up the changes, consistent with how the runtime treats other state that is mutated in place. Element properties that hold the same object, such as a video's `srcObject`, are still not reassigned, so the element doesn't reload.
