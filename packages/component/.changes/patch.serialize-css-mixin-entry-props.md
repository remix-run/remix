Fix hydration of `clientEntry` components whose props contain JSX elements styled with `css()`. The server serialized each `css()` mixin as a bare `{ "args": [...] }` object without the mixin itself, so hydration failed with `Framework invariant: Invalid mix prop` and the client entry never became interactive. `css()` mixins in client entry props now round-trip to the browser with their styles, including nested elements and arrays like `mix={[css(base), css(active)]}`, and content from those props that the server didn't render is styled when the client entry renders it later.
