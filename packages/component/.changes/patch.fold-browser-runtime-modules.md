The browser runtime loads fewer modules, with no behavior changes. Pages that hydrate with `run()` load 23 component modules instead of 35. Apps that only use `createRoot()` or `createRangeRoot()` load 16 instead of 23 and about 6% less gzipped code, and code that only uses `clientEntry`, `css`, `on` and `ref` loads 9 instead of 13 and about 19% less. `updateUrl()` and `spaResponse` now load only in apps that import them.
