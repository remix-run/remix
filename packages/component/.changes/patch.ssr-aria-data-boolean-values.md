Server rendering no longer drops boolean `aria-*` and `data-*` values. `renderToString()` and `renderToStream()` now render `true` and `false` as `"true"` and `"false"`, matching the browser runtime. For example, `<a aria-current={true} aria-hidden={false}>` previously rendered as `<a aria-current>`, which assistive technology reads as `aria-current="false"`. Remix's own `data-rmx-*` markers, such as `data-rmx-document`, still render as empty attributes when `true` and are omitted when `false`.
