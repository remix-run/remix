Frame reloads can retain a followed redirect's final URL with `frame.reload({ adoptRedirectSrc: true })`. A mutation that redirects to a frame's updated content can render it and establish the source for later GET reloads in one call, without changing browser history. The source updates after successful rendering and before completion events and promises settle; failed, cancelled, and superseded reloads do not adopt it. Reloads retain the requested source by default.
