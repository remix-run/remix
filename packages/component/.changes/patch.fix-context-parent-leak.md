Release earlier renders' vnode trees while a component or mixin stays mounted. Context lookups for component handles and mixins started from the parent they mounted under, which kept that render's whole vnode tree reachable for as long as they lived. Each long-lived component or mixin mounted during a later render pinned another copy, so a page that re-rendered on every interaction grew its heap until the tab ran out of memory. Lookups now start from the parent of the latest render.
