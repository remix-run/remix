Fix flashes of unstyled content during client navigation when page-specific `<head>` links are added or removed ahead of keyed stylesheets. DOM diffs now move only the elements whose order changed, so keyed elements that keep their order, such as `<link data-rmx-key rel="stylesheet">` or keyed iframes, are no longer detached and re-inserted. Unkeyed `<link>` elements are also no longer repurposed for a link with a different `rel` or `href`, which could turn a `modulepreload` into an `alternate` link or swap the stylesheet an existing link loads. (see #12064)
