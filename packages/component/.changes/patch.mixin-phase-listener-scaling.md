Mixins that listen for `beforeUpdate` or `commit`, such as `animateLayout()` from `@remix-run/ui`, no longer get quadratically slower as more elements use them. Mounting or removing one used to scan every other mounted mixin with a phase listener, so rendering 20,000 such elements took about 1.4 seconds in Chromium. It now takes about 220 ms and grows linearly with the element count.
