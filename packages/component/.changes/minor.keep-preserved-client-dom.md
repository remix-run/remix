Keep client-owned elements connected across frame reloads with the boolean `data-rmx-client-dom` attribute, including portal hosts in arbitrary containers. These elements retain their live attributes and children, preserving focus, transitions, and scroll position, and are excluded from server matching even when incoming HTML has the same key. Client code removes them or removes the attribute to return them to server reconciliation. Removing their parent still removes them. Server rendering and initial hydration still process their initial content.

`data-rmx-preserve-dom` retains its existing behavior: matched elements keep their live attributes and children, while the server can remove them by omission or resume normal reconciliation by removing the attribute. If both attributes are present, `data-rmx-client-dom` takes precedence.
