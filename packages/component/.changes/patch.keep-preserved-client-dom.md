Keep client-created elements with `data-rmx-preserve-dom` when a frame reload's incoming HTML doesn't include them. Previously the diff removed them, so a portal host appended to `<body>` was detached and re-added, which blurred focus, restarted CSS transitions, and reset scroll inside open overlays. Unmatched preserved elements stay in place without moving matched siblings, and new siblings are inserted before trailing ones. Unkeyed preserved elements keep their identity and client-owned contents when ordinary siblings precede them and only pair with incoming preserved elements.
