Keep text typed and checkboxes or radios toggled before a form control hydrates. Hydration used to overwrite those edits with the server-rendered `value` or `checked`, so text typed into a field that streamed in with a frame was lost if its client entry hydrated a moment later. The edit is now kept and replayed as `input` and `change` events once the control's handlers are attached, so app state such as a live search query catches up with what the user sees.
