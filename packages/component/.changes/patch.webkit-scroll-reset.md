Fix frame navigations in iOS Safari that opened the next page scrolled to the bottom after scrolling down the previous page. Safari restored the previous scroll position, clamped to the new page's height, for several frames after the navigation reset it to the top. Remix now reapplies the reset in WebKit until it holds, including when the new page grows after Safari clamps the position, as it does while images load on a first visit, and stops as soon as the user scrolls or other code moves the page (see #12011).
