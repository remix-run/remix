Fix a link click, form submission or `navigate()` call that interrupts a navigation before its page renders leaving a history entry for the page that never rendered. The new navigation now replaces that entry, so Back returns to the page the visitor saw, including when a `currententrychange` listener starts it before rendering begins. Links and GET forms with `data-rmx-history="replace"` also replace the entry before their navigation commits in browsers that support it, as POST forms already did, instead of cancelling the navigation and starting a replacement.
