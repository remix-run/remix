Setting a `data-rmx-*` attribute to `false` no longer turns its behavior on in the browser. For example, `<a href="/login" data-rmx-document={false}>` rendered as `data-rmx-document="false"`, which still opted the link out of client navigation, and `data-rmx-preserve-dom={false}` still preserved the element's DOM. Remix's `data-rmx-*` attributes now follow HTML boolean attribute rules in both server rendering and the browser: `true` renders an empty attribute and `false` omits it. The exceptions are `data-rmx-reset-scroll` and `data-rmx-reset-focus`, where Remix reads `"false"` as `"manual"`, so boolean values render as `"true"` and `"false"` on the server as well as in the browser.
