SVG `xlinkHref` and `xlink:href` props now render as the SVG2 `href` attribute on the server and in the browser, so `<use xlinkHref="#icon-star" />` renders `<use href="#icon-star">` instead of `<use xlink:href="#icon-star">`. All supported browsers resolve `href` on SVG elements. Update any CSS selectors, tests, or scripts that look for `xlink:href` in rendered SVG.
