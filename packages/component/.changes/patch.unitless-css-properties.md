Numeric values for unitless CSS properties no longer get a `px` suffix in `css()` and the `style` prop. Previously only a small set of properties stayed unitless, so values like `WebkitLineClamp: 4` rendered as the invalid `-webkit-line-clamp: 4px` and `flex: 1` rendered as `flex: 1px`, which the shorthand reads as a `1px` flex basis. The unitless list now includes every property React treats as unitless, covering properties such as `lineClamp`, `flex`, `scale`, `tabSize`, `animationIterationCount`, `gridRowStart`, `strokeWidth`, and `fillOpacity`, along with their vendor-prefixed forms.
