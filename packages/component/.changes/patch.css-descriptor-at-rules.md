Fix `css()` dropping `@property`, `@font-face`, `@counter-style`, `@font-palette-values`, and `@page` rules. Their descriptors were nested inside the generated class, which is invalid CSS, so the browser discarded the rule and a custom property, font, counter, palette, or page rule written next to the style that uses it never registered. These rules are now emitted before the class, inside the style's `@layer`, with descriptor names kebab-cased. Conditional rules such as `@media` and `@supports` still wrap the class.
