Fix controlled date and time inputs (`date`, `datetime-local`, `month`, `time` and `week`) undoing what the user picked or typed. With a `change` handler, each pick or keystroke was put back on the `input` event that comes first, so the handler only ever saw the old value; these inputs now wait for `change`, as checkboxes and selects already did. With an `input` handler, clearing one part of a date, such as the month, wiped the whole input: its value is empty until every part is filled in, and writing that empty value back cleared the other parts. A controlled value the input already holds is no longer written again.
