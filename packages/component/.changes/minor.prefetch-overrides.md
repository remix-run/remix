Customize speculative loading with `defaultPrefetch(src, options, { fetch, frame })`. Override prepared HTML requests or handle discovered assets and nested frame references with native prefetch hints, application fetches, and image loaders. Select nested sources explicitly through `prefetchReferences({ frames })`; each reference exposes `src`, `target`, and `fallback`. HTML requests use low priority and send `X-Remix-Prefetch: true`.

Call `prefetch(anchor, { signal })` to use its navigation destination and cancel when the anchor disconnects or its destination or eligibility changes. Declarative triggers also cancel when their prefetch marker is removed or disabled. Hooks receive the initiating element and a signal that retains shared work while another caller needs it. See [Prefetching](https://github.com/remix-run/remix/blob/main/packages/component/README.md#prefetching) for discovery rules and examples.
