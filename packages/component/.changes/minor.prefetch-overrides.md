Customize speculative loading with `defaultPrefetch(src, options, { fetch, frame })`. The `fetch` hook receives Remix's prepared HTML request, including `X-Remix-Prefetch: true` so servers can identify speculative requests and shed them under load. After parsing, the `frame` hook receives an inert fragment, original asset declarations with usable HTTP(S) sources, and all discovered same-origin nested frame references with their source, target, and whether they declare fallback content. Delegate selected references through `prefetchReferences()` or handle them with application-managed `Image` instances, fetches, and queues.

The default discovers scripts, stylesheets, module preloads, and explicit preloads for `fetch`, `font`, `image`, `script`, `style`, and `track`. Missing, blank, malformed, and non-HTTP(S) sources are omitted. Responsive image preloads with nonempty `imagesrcset` are exposed unchanged to the `frame` hook, even without an `href`; Remix does not parse their source sets or prefetch their fallback URLs. Applications can handle responsive images in the hook while delegating other assets to native prefetch hints.

Pass an anchor directly to `prefetch(anchor)` to use its navigation source and frame target, expose it through the prefetch handler's `options.element`, and cancel its caller when it disconnects, its effective destination changes, or it becomes ineligible for frame navigation. Anchor calls accept only `signal` in their options; string calls accept `target` and `signal` and have no triggering element. The handler's `PrefetchFrameOptions` retains the runtime-supplied element when forwarded to `defaultPrefetch`. Declarative triggers have the same cancellation behavior and also cancel when `data-rmx-prefetch` is removed or disabled; imperative calls do not require the marker. Hash-only changes, document moves, viewport exit, and switching between supported trigger modes retain existing work. Both hooks expose the initiating caller's live `context.element`, including for nested requests; later callers sharing a request do not replace it.

Select nested sources explicitly with `prefetchReferences({ frames })` to fetch their HTML and discover their assets. Omitted assets retain discovered defaults; omitted frames start no nested-source requests. No additional `<Frame>` prop is required. Nested requests use the same overrides, preserve named-frame headers, and terminate cycles. `options.signal` cancels individual callers while retaining shared work; runtime disposal cancels delegated work. Completed HTML is still discarded, and navigation continues to use the frame resolver and browser cache.
