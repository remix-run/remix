Customize speculative loading with `defaultPrefetch(src, options, { fetch, frame })`. The `fetch` hook receives Remix's prepared HTML request. After parsing, the `frame` hook receives an inert fragment, original asset declarations, and opted-in nested frame references. Delegate selected references through `prefetchReferences()` or handle them with application-managed `Image` instances, fetches, and queues.

Automatic triggers include their marked link in `options.elements`. Both hooks expose the current shared callers' live elements through `context.elements`, allowing apps to prioritize queued work by link position or inspect whether a link remains connected. Imperative calls can supply their own elements, and nested requests inherit parent origins.

Add `prefetch` to a nested `<Frame>` to fetch its HTML and discover its assets when the containing page is prefetched. Nested requests use the same overrides, preserve named-frame headers, and terminate cycles. `options.signal` cancels individual callers while retaining shared work; runtime disposal cancels delegated work. Completed HTML is still discarded, and navigation continues to use the frame resolver and browser cache.
