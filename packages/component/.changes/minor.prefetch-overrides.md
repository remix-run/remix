Customize speculative loading with `defaultPrefetch(src, options, { fetch, frame })`. The `fetch` hook receives Remix's prepared HTML request. After parsing, the `frame` hook receives an inert fragment, original asset declarations, and all discovered same-origin nested frame references. Delegate selected references through `prefetchReferences()` or handle them with application-managed `Image` instances, fetches, and queues.

Pass an anchor directly to `prefetch(anchor)` to read its frame destination metadata, expose it through `options.element`, and cancel its caller when it disconnects. Declarative triggers have the same cancellation behavior. Both hooks expose the initiating caller's live `context.element`, including for nested requests; later callers sharing a request do not replace it. String calls can supply an element explicitly without attaching a DOM lifetime.

Select nested sources explicitly with `prefetchReferences({ frames })` to fetch their HTML and discover their assets. Omitted assets retain discovered defaults; omitted frames start no nested-source requests. No additional `<Frame>` prop is required. Nested requests use the same overrides, preserve named-frame headers, and terminate cycles. `options.signal` cancels individual callers while retaining shared work; runtime disposal cancels delegated work. Completed HTML is still discarded, and navigation continues to use the frame resolver and browser cache.
