Restore `<select>` selections from `value` or `defaultValue` during server rendering, including options inside components and optgroups and implicit values from trusted option HTML. Single-select defaults and scalar controlled values select the first matching option. In the browser, `defaultValue` initializes the selection and native reset defaults. Later changes or removal are ignored unless `multiple` changes, matching React’s select default behavior.

Explicit option `selected` props override `defaultValue` consistently during server rendering, client mounting, hydration, and native reset. Controlled `value` takes precedence over option selections and stays synchronized when nested option components, mixins, or separate client roots update.
