Rerendering elements that use mixins is faster. The runtime no longer creates and dispatches `beforeUpdate` and `commit` events for a host when none of its mixins listen for them, which covers built-in mixins like `css()`, `attrs()`, and `link()`. In a benchmark that rerenders 200 cards styled with `css()`, each rerender takes about 18% less time. Mixins that listen for these events, such as `animateLayout()`, receive them as before.
