Bind `Date` and boolean parameters consistently. Previously, a `Date` in the first parameter position was read as a named-bindings object in Node.js, shifting the remaining values, and a `Date` anywhere else failed, which broke `timestamp` column writes, including the default `created_at` and `updated_at` values. Dates are now bound as UTC strings in SQLite's `current_timestamp` format, such as `'2026-06-01 12:00:00'` (with milliseconds only when they are nonzero), and booleans in raw `sql` statements are bound as `1` or `0` like query builder values. Invalid dates are rejected.

Object and array parameters other than typed arrays are now rejected in both Node.js and Bun. In Bun, an object parameter was previously read as a set of named bindings; pass each value positionally instead.
