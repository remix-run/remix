Bind `Date` and boolean parameters consistently. Previously, a `Date` in the first parameter position was bound as `NULL` in Node.js, and a `Date` anywhere else failed, which broke `timestamp` column writes, including the default `created_at` and `updated_at` values. Dates are now bound as ISO 8601 strings, and booleans in raw `sql` statements are bound as `1` or `0` like query builder values. Other object and array parameters are rejected instead of being read as named bindings, so they now fail the same way in Node.js and Bun.
