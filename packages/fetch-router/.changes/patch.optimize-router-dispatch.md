`createRouter()` dispatches requests much faster. In our benchmarks, a request to a static route is about 4 times as fast as in 1.0.1, a request to a route with a param about 7 times as fast, and a request through three middleware 2 to 4.5 times as fast. The router no longer parses the request URL unless a handler or middleware reads `context.url`, routes are indexed by request method, `RequestContext` allocates context storage only when first used, and middleware chains create fewer promises and abort listeners. Routing behavior is unchanged, and routers configured with a custom `matcher` continue to use it for every request.
