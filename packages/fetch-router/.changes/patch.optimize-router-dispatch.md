`createRouter()` dispatches requests significantly faster in our benchmarks, especially for static routes and middleware chains. Routes are indexed by request method with a direct lookup for plain static pathnames, `RequestContext` lazily creates `url`, `params`, context storage, and bound `get`/`has`/`set` helpers on first use, and synchronous handlers and middleware skip per-layer promise overhead. Routing behavior is unchanged, and routers configured with a custom `matcher` continue to use it for every request.
