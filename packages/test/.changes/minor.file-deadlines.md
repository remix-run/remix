Test files now fail after ten minutes of execution per browser project, reporting the file and project instead of stalling the run. The deadline includes imports and cleanup, excludes time queued for a worker, and terminates timed-out workers or browser frames/pages so queued files can continue. Set `fileTimeout` in `runRemixTest()` options to customize the deadline in milliseconds, or use `0` to disable it. Existing individual test, hook, and browser progress timeouts still apply.
