Improve compilation throughput, warm response latency, and memory usage across scripts, styles, and cached file transforms. Cold `getScriptEntry()` and `getPreloads()` calls now compute the optimized module graph once and resolve/emit dependencies concurrently, warm `getScriptEntry()` calls avoid `structuredClone`, watch mode no longer clears the `oxc-resolver` cache on every module with a bare import, and active browser HMR channels no longer spawn a second `chokidar` watcher.

Reduce memory retention by releasing intermediate transform state after emit when `watch` is `false`, bounding emitted script and style caches with an LRU byte limit, skipping duplicate `.map` assets when `sourceMaps` is `'inline'`, and avoiding redundant body hashing on `createFsFileCache()` hits. Asset responses now include `Content-Length` on `200` and `HEAD` responses and `Cache-Control` on `304` responses.
