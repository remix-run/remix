Add an `optimizeBarrelFileImports` option that rewrites named imports through eligible barrel files to their resolved implementation modules. This avoids intermediary requests and removes side-effect-free dependency branches that are no longer reachable while preserving package export restrictions. It works with generated import maps, rewritten import URLs, fingerprinting, source maps, custom loaders, and watch mode. With browser HMR enabled, script and package metadata changes trigger a full reload while stylesheet updates remain hot.
