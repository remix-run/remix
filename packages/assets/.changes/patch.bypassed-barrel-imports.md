Avoid loading unrelated modules through barrel files that optimized imports already bypass. When a module behind a barrel file also imports from another barrel file, such as `@remix-run/component`, served importers previously requested that inner barrel file to preserve evaluation order, which loaded every module it re-exports. Importers now request only the modules that still load, in the same order. For example, `import { animateLayout } from '@remix-run/ui/animation'` now loads 6 framework modules instead of 36, and `import { onInputValidation } from '@remix-run/ui/form'` loads 9 instead of 36.
