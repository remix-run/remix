Fix full-page HMR reloads in WebKit rendering stale JavaScript when a module had been preloaded. With HMR enabled, the asset server now sends `Vary: *` on compiled JavaScript responses to WebKit so the browser always requests current modules. This can add a request for a preloaded dependency, and because the Cache API rejects responses with `Vary: *`, a service worker can't cache these development scripts in WebKit.
