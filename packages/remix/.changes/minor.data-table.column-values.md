`remix/data-table` query builder rows now have the same JavaScript shape on every adapter: `json()` columns are serialized on write and parsed on read, `boolean()` columns read as `true` or `false`, and `timestamp()` columns read as `Date` objects. Arrays interpolated into `sql` expand into `in` lists. See the [`data-table` changelog](https://github.com/remix-run/remix/blob/main/packages/data-table/CHANGELOG.md) for details.
