`remix/node-fetch-server` now validates the request host for every handler. Hosts with a path, query, fragment, userinfo, whitespace, or control characters, from the `host` option, a trusted forwarding header, HTTP/2 `:authority`, or `Host`, make `createRequest()` throw and make `createRequestListener()` respond with `400 Bad Request` unless `onError` returns a response. An invalid trusted `X-Forwarded-Host` is now rejected instead of falling back to `Host`. See the [`@remix-run/node-fetch-server` changelog](https://github.com/remix-run/remix/blob/main/packages/node-fetch-server/CHANGELOG.md) for details.
