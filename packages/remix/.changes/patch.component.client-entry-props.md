`clientEntry` props in `remix/component` hydrate more reliably. JSX elements styled with `css()` in props no longer fail hydration with `Invalid mix prop`, and plain data that contains keys Remix uses for serialization, such as `$rmx`, now reaches the client entry unchanged. Only elements created with JSX or `createElement()` render; objects that merely look like elements, such as ones parsed from JSON, now throw `Invalid child node`, so data from a database or API can't inject markup.
