Match `request.url` faster with `createMultiMatcher({ lazyMatches: true })` from `remix/route-pattern/match`, which skips parsing URL strings and computes `match.url` and `match.paramsMeta` only when they are read. `remix/router` uses lazy matches internally. See the [`@remix-run/route-pattern` changelog](https://github.com/remix-run/remix/blob/main/packages/route-pattern/CHANGELOG.md) for details.
