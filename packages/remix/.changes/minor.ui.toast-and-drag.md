The standalone `@remix-run/ui` package now supports accessible toast notifications with typed data and dragging that composes with entrance, exit and layout animations. Entrance and exit animations also support per-property timing overrides. Supporting `remix/component` changes improve keyed element restoration during animations.

See the [UI changelog](https://github.com/remix-run/remix/blob/main/packages/ui/CHANGELOG.md) and [component changelog](https://github.com/remix-run/remix/blob/main/packages/component/CHANGELOG.md) for details.
