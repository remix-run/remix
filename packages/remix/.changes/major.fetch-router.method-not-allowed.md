BREAKING CHANGE: The router from `remix/fetch-router` now responds with `405 Method Not Allowed` (including an `Allow` header) when a request URL matches a route pattern but no route is registered for the request method, instead of falling through to the 404 `defaultHandler`. Customize the response with the new `methodNotAllowedHandler` option in `createRouter()`. `GET` routes also serve `HEAD` requests automatically now, returning the same status and headers with an empty body. See the `@remix-run/fetch-router` changelog for details.
