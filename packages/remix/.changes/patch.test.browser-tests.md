Browser tests in `remix/test` run faster by reusing compiled scripts across test files. Firefox runs each test file in a top-level window so Back and Forward navigations behave as they do in the browser, and WebKit runs recover from the browser's history quota instead of failing later test files. See the [`@remix-run/test` changelog](https://github.com/remix-run/remix/blob/main/packages/test/CHANGELOG.md) for details.
