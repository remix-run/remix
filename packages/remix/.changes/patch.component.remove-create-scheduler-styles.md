`createScheduler()` from `remix/component` no longer accepts its unused third `styles` argument. Passing it had no effect, so runtime behavior is unchanged, but TypeScript calls with three arguments now fail to type-check. Call `createScheduler(document, errorTarget)` instead. See the [`@remix-run/component` changelog](https://github.com/remix-run/remix/blob/main/packages/component/CHANGELOG.md) for details.
