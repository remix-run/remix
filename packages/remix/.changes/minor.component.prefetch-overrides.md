Customize prefetching through `defaultPrefetch` from `remix/component`. Override HTML fetching and handle discovered assets and nested frame references with native hints or application-managed image loading and queues. Hooks expose the initiating element for application scheduling. Pass an anchor to `prefetch(anchor)` to use its frame metadata and cancel its caller when it disconnects; declarative triggers have the same cancellation behavior. Select nested sources explicitly through `prefetchReferences({ frames })`; the default discovers embedded assets without fetching those sources separately. Cancel speculative work with `options.signal`.
