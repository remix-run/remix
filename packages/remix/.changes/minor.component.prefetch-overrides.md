Control speculative HTML and asset loading with `defaultPrefetch` from `remix/component`, using native hints or application fetches, image loaders, and queues. Hooks expose discovered references, the initiating element, and cancellation; `prefetch(anchor)` follows the link's navigation destination and lifetime. See [Prefetching](https://github.com/remix-run/remix/blob/main/packages/component/README.md#prefetching) for usage.
