Customize prefetching through `defaultPrefetch` from `remix/component`. Override HTML fetching and handle discovered assets and nested frame references with native hints or application-managed image loading and queues. HTML prefetches send `X-Remix-Prefetch: true` so servers can identify speculative requests. Hooks expose the initiating element for application scheduling. Pass an anchor to `prefetch(anchor)` to use its navigation source and frame target and cancel its caller when it disconnects; anchor options accept only `signal`, and declarative triggers have the same cancellation behavior. Use each frame reference's boolean `fallback` to select nested sources explicitly through `prefetchReferences({ frames })`; the default discovers embedded assets without fetching those sources separately. Cancel speculative work with `options.signal`.
