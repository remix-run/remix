Server rendering with `remix/component/server` (`renderToString()` and `renderToStream()`) is faster and uses less memory, with no changes to app code. In our benchmarks on Node 24, `renderToString()` throughput improves 2.4x–6.7x and `renderToStream()` improves 1.1x–5.4x while producing identical HTML output. See the [`@remix-run/component` changelog](https://github.com/remix-run/remix/blob/main/packages/component/CHANGELOG.md) for details.
