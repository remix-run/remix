Request and response handling in `remix/node-fetch-server` (`createRequestListener()`, `createRequest()`, and `sendResponse()`) has higher throughput and lower per-request overhead. As part of this change, `sendResponse()` no longer releases its reader lock on the consumed `response.body` stream, bodyless HTTP/1.x requests (`Content-Length: 0` or neither `Content-Length` nor `Transfer-Encoding`) now leave `request.body` as `null` instead of an empty stream, and `createRequestListener()` always constructs and passes a `Request` to zero-argument or rest-parameter handlers while routing their errors through `onError`. See the [`@remix-run/node-fetch-server` changelog](https://github.com/remix-run/remix/blob/main/packages/node-fetch-server/CHANGELOG.md) for details.
