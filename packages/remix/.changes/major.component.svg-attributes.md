SVG elements rendered with `remix/component` now pass attribute names through as written instead of converting React-style camelCase props (such as `strokeWidth` or `strokeLinecap`) to kebab-case or XML/XLink namespaces. Only `className` (`class`) and `xlinkHref` / `xlink:href` (`href`) are normalized. Update SVG JSX props to use standard SVG attribute names like `stroke-width`, `stroke-linecap`, and `viewBox`.
