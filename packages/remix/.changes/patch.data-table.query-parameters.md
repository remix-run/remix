`remix/data-table` adapters now bind each query parameter as exactly one value. The MySQL and SQLite adapters reject array and plain-object parameters, MySQL no longer substitutes values into question marks inside quoted text or comments, SQLite binds `Date` values as ISO 8601 strings, and the query builder serializes `json()` column values. See the [`data-table-mysql`](https://github.com/remix-run/remix/blob/main/packages/data-table-mysql/CHANGELOG.md) and [`data-table-sqlite`](https://github.com/remix-run/remix/blob/main/packages/data-table-sqlite/CHANGELOG.md) changelogs for details.
