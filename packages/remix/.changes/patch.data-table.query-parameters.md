Every `remix/data-table` adapter now binds each query parameter as exactly one value. In raw SQL, serialize JSON with `JSON.stringify()` and write one placeholder per `IN` list item; the query builder serializes `json()` column values for you. See the [`data-table`](https://github.com/remix-run/remix/blob/main/packages/data-table/CHANGELOG.md), [`data-table-mysql`](https://github.com/remix-run/remix/blob/main/packages/data-table-mysql/CHANGELOG.md), and [`data-table-sqlite`](https://github.com/remix-run/remix/blob/main/packages/data-table-sqlite/CHANGELOG.md) changelogs for adapter-specific changes.
