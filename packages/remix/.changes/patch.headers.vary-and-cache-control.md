`Vary` from `remix/headers` keeps header names as they were first given, so `compression()` and `cors()` no longer rewrite `Vary: Cookie` to `Vary: cookie`. Safari only varies its cache on cookies when the name is spelled `Cookie`, so the lowercased value could let it reuse a private response for a different session. `Vary: *` is also preserved instead of becoming an invalid value like `Vary: *, Accept-Encoding`, and `CacheControl.from()` no longer drops directives whose names aren't lowercase, such as `No-Store`.
