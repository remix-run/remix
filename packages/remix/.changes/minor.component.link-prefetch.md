Prefetch frame HTML and assets with `data-rmx-prefetch="intent"`, `data-rmx-prefetch="viewport"`, or the imperative `prefetch()` API from `remix/component`. Both link modes support named frames and source overrides, respect Save-Data, and skip `slow-2g`/`2g` connections. Browsers without prefetch-hint support use low-priority asset fetches. See the [prefetching guide](https://github.com/remix-run/remix/blob/main/packages/component/docs/frames.md#prefetching) for usage, customization, and caching behavior (see #12004).
