Add `data-rmx-prefetch="intent"` or `data-rmx-prefetch="viewport"` to links, or call `prefetch(href, options?)` from `remix/component`, to start loading frame content before a visitor opens it. Intent links prefetch on hover, focus, or press; viewport links prefetch when they enter view, including links added during frame navigation or client rendering. Named-frame links honor `data-rmx-target` and `data-rmx-src`; imperative calls accept `{ target }`. Remix fetches HTML to discover JavaScript, CSS, and explicit image and font preloads for asset prefetch hints, then leaves navigation and response caching to the browser. Even uncacheable HTML can reveal cacheable assets. `run({ prefetch })` lets apps replace this strategy and receives the source and optional target (see #12004).
