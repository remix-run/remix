Add `data-rmx-prefetch="intent"` to links, or call `prefetch(href)` from `remix/component`, to start loading pages before a visitor opens them. Use `render` to start when a link enters the DOM, or `viewport` when it enters the viewport. Remix fetches HTML to discover JavaScript, CSS, and explicit image and font preloads for asset prefetch hints, then leaves navigation and response caching to the browser. Even uncacheable HTML can reveal cacheable assets. `run({ prefetch })` lets apps replace this strategy (see #12054).
