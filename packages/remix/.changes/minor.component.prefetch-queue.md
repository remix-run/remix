Schedule HTML prefetching through `run({ prefetch: { concurrency, filter, priority } })` from `remix/component`. Remix owns a queue with three concurrent HTML requests by default, caches priorities until layout or application state changes, and cancels speculative work whose links are removed. Use `app.invalidatePrefetch()` to refresh queued policies and `prefetch(src, { signal })` for caller cancellation. Asset and nested-frame discovery remain built in, and existing function handlers remain supported.
