`remix/data-table/sqlite` binds `Date` parameters as UTC strings in SQLite's `current_timestamp` format. Previously, writing a `timestamp()` column, including the default `created_at` and `updated_at` values, could fail or shift the remaining parameters in Node.js. See the [`data-table-sqlite` changelog](https://github.com/remix-run/remix/blob/main/packages/data-table-sqlite/CHANGELOG.md) for details.
