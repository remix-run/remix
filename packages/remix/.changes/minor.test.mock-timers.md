Test time-dependent code with `t.mock.timers` from `remix/test`. Control Date and timers together with one shared clock engine across Node, Bun, and browsers, and restore the clock automatically after each test. Node and Bun test workers also control timer-module calls and promise timers. Existing `t.useFakeTimers()` handles retain their progressive behavior. See the [test package documentation](https://github.com/remix-run/remix/tree/main/packages/test#system-time-and-timers) for runtime details.
