Beta.6 adds an integrated full-stack hot module replacement workflow. New projects include an `npm run hmr` command and `hmr.ts` runner, while `remix/node-hmr`, `remix/ui-hmr`, and `remix/assets` coordinate server and browser updates through `import.meta.hot`. Browser-reachable source is now scaffolded in colocated `public/` directories, including `app/actions/public/entry.ts`, so the files that cross the server/browser boundary are explicit. Existing asset servers can also use `allowPackages` to serve an allowed package and its dependencies.
