Use `replaceUrl(href, options?)` from `remix/component` to reflect state the page already displays in the URL without fetching, rendering, adding a history entry, or moving scroll and focus. Remix keeps frame sources and history state in sync for later reloads and Back/Forward. Replacement waits for any current navigation and rejects if it fails, is superseded, or changes destination. Pass a same-origin URL and an optional `signal` to cancel pending replacement when its component unmounts or its work becomes stale.
