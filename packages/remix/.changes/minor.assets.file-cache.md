Customize transformed-file caching in `remix/assets` with the exported `FileCache` interface and its `get` and `put` methods. Existing `FileStorage` configurations remain supported. Set `files.cache: true` to opt into a persistent filesystem LRU cache, or supply `createFsFileCache(directory, { maxEntries, maxFileSize, maxTotalSize })` to choose its directory and limits. Caching remains disabled when the option is omitted or `false` (see #11859).
