Customize transformed-file caching in `remix/assets` with the exported `FileCache` interface and its `get` and `put` methods. Existing `FileStorage` configurations remain supported. Set `files.cache: true` to opt into a filesystem LRU cache, or supply `createFsFileCache({ directory, maxEntries, maxFileSize, maxTotalSize })` to choose its directory and limits. Caching remains disabled when the option is omitted or `false` (see #11859). Use one cache instance per directory, or provide a custom cache for shared multi-process use. Cached files survive restarts; read recency stays in memory.
