The `remix/component` browser runtime is smaller, with no changes to app code. In our measurements, a minimal `createRoot()` app is about 40% smaller minified and gzipped, and an app that hydrates with `run()` is about 10% smaller. Standalone roots and navigation helpers such as `navigate()` only load the code for the features they import, apps served unbundled by `remix/assets` make fewer module requests, and list, frame, and hydration updates do less work. See the [`@remix-run/component` changelog](https://github.com/remix-run/remix/blob/main/packages/component/CHANGELOG.md) for details.
