SQL migrations loaded through `remix/data-table/migrations/node` or `remix db` accept zero-padded sequential prefixes such as `0001` or `YYYYMMDDHHmmss` timestamps such as `20260228090000` (`2026-02-28 09:00:00`) to record creation time and sort chronologically. Prefixes must contain 1 to 64 digits, with the same number of digits throughout a migration directory to preserve numeric ordering.
