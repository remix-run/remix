Use `updateUrl(href, options?)` from `remix/component` to reflect state the page already displays in the URL without fetching, rendering, or moving scroll and focus. It replaces the current entry by default; `history: 'push'` adds an entry for Back/Forward. Remix keeps the top-frame source and history state in sync. Calls capture the browser URL, wait for active navigation, and reject if it fails or an unrelated navigation or URL change invalidates that context. Preceding queued updates are allowed, and calls apply in order so the last applicable call wins. Native interception is awaited; cancellation or failure after dispatch does not roll back history. Pass a same-origin URL and an optional `signal` to cancel stale work. Without frame navigation, applications restore displayed state on Back/Forward themselves.
