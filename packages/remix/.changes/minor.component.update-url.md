Use `updateUrl(href, options?)` from `remix/component` to reflect state the page already displays in the URL without fetching, rendering, or moving scroll and focus. The current history entry is replaced by default; `history: 'push'` adds an entry for Back/Forward. Remix keeps the top-frame source and history state in sync for later reloads and history traversal. Updates wait for any current navigation and reject if it fails, is superseded, or changes destination. Precommit waits reject with an `AbortError` if the browser does not expose the destination; call after commit or completion in that case. Calls waiting for the same navigation apply in call order. Native interception is awaited; failures after commit leave the updated URL in place. Without frame navigation, applications must restore displayed state on Back/Forward themselves. Pass a same-origin URL and an optional `signal` to cancel a pending update when its component unmounts or its work becomes stale.
