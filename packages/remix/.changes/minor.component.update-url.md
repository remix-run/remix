Use `updateUrl(href, options?)` from `remix/component` to reflect locally rendered state in the URL without fetching, rendering, or changing scroll/focus. It replaces the current entry by default; `'push'` adds an entry. Remix keeps history state and the top-frame source in sync. The promise resolves with an `AbortSignal`, aborted if canceled or superseded; actual failures reject. Only the latest waiting call applies. Pass a `signal` to cancel stale work. Native interception is unsupported.
