Use `updateUrl(href, options?)` from `remix/component` to reflect state the page already displays in the URL without fetching, rendering, or moving scroll and focus. The current history entry is replaced by default; `history: 'push'` adds an entry for Back/Forward. Remix keeps frame sources and history state in sync for later reloads and history traversal. Updates wait for any current navigation and reject if it fails, is superseded, or changes destination. Pass a same-origin URL and an optional `signal` to cancel a pending update when its component unmounts or its work becomes stale.
