Use `updateUrl(href, options?)` from `remix/component` to reflect locally rendered state in the URL without fetching, rendering, or changing scroll and focus. It replaces the current entry by default; `'push'` adds an entry. Remix keeps history state and the top-frame source in sync. Only the latest waiting call applies; canceled or invalidated calls reject with `AbortError`. Pass a `signal` to cancel stale work. Native interception of the update is unsupported.
