Customize frame fetching and rendering with `defaultResolveFrame` from `remix/component`. Its `{ fetch, commit }` overrides let apps manage cached responses and animate navigations, including followed redirects. Resolvers receive the original browser `transition`; `commit` receives the resolved destination, and `commitFrame()` waits for rendering and navigation completion. See the [bookstore demo](https://github.com/remix-run/remix/tree/main/demos/bookstore#view-transitions) for traversal caching and shared cover/title animations.
