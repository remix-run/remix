Follow reloads with `reloadStart` from `remix/component`, now a `FrameReloadStartEvent` with the initiating reload's `src`, `method`, `encType`, `formData`, `element`, and `submitter`, plus a `finished` promise that always resolves with `{ error, aborted }`. Request details align with `frame.reload()` options. See the `@remix-run/component` changelog for an example.
