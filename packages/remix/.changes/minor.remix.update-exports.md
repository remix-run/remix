Validate native form submissions with the new `remix/data-schema/form` export (see #11630). Form schemas describe input kinds and use functional `fd.parse(schema, data)` and `fd.parseSafe(schema, data)` APIs for `FormData` or `URLSearchParams`. Safe failures include restorable values and grouped errors for rendering form feedback. Single selects restore submitted values in server-rendered and hydrated forms. Set `{ sensitive: true }` on scalar fields to omit their failed values; passwords are always omitted. Successful parsing still returns sensitive values; ordinary `remix/data-schema` parsing keeps its existing result shape.
