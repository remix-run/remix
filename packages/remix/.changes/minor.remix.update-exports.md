Validate native form submissions with the new `remix/data-schema/form` export. Form schemas describe input kinds and use functional `fd.parse(schema, data)` and `fd.parseSafe(schema, data)` APIs for `FormData` or `URLSearchParams`. Safe failures include restorable values and grouped errors for rendering form feedback. Single and multiple selects restore submitted values in server-rendered and hydrated forms; `fd.fields` also supports checkbox-group validation and restoration. Multiple selects accept array values and defaults through `remix/component`. Set `{ sensitive: true }` on scalar fields to omit their failed values; passwords are always omitted. Successful parsing still returns sensitive values; ordinary `remix/data-schema` parsing keeps its existing result shape.
