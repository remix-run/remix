Follow frame navigations with `rmx:navigation` from `remix/component`: listen on a source link or form for contextual pending UI, or on `window` in capture mode for links, forms, programmatic navigation, and Back/Forward. The event exposes the initiating `element` (null without a source), optional submission details, initial browser destination `to`, requested `frameSrc`, and named `frameTarget`, and one completion promise through redirects, scroll, and focus.
