Follow a form's own submissions with the typed `onSubmission()` mixin from `remix/component`. It listens for `rmx:submission`, dispatched on the submit button or form when a submission starts a frame reload. Its `FormSubmissionEvent` extends the native `SubmitEvent` with the same request details and `finished` promise as the target frame's `reloadStart`. `finished` always resolves with `{ error, aborted }`, keeping cancellation checks out of components. It is noncancelable; cancel submissions through native `submit`. See the `@remix-run/component` changelog for an example.
