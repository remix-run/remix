Project tooling now shares an optional JSONC `remix.json` file. It configures `remix test`, strict `remix doctor` checks, and the new `remix db` workflow, with command-line flags taking precedence. `remix db` can inspect migration status, migrate, seed, wipe, and reset SQLite, PostgreSQL, and MySQL databases; destructive commands require `--force`. The test runner also adds `--only` for focused suite or test-name matching, `--quiet` to omit skipped tests, and a default `NODE_ENV` of `test` when the environment does not already provide one.
