`createHref()` now throws a `CreateHrefError` with `details.type` of `invalid-pathname-variable` when a pathname variable produces a standalone `.` or `..` segment, such as `createHref('/posts/:id', { id: '..' })`. URL parsers remove these segments, so the generated href could resolve to a different route. This also applies to the `href()` method of routes created with `route()` from `remix/routes`.
