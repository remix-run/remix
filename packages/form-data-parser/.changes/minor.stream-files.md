`parseFormData()` can stream file uploads straight to storage with the new `streamFiles` option instead of buffering each file in memory first. With `streamFiles: true`, the `uploadHandler` is called as soon as a file's headers arrive, and the upload's contents are read from the request as the handler reads them, so `await fileStorage.set(key, upload)` writes a large upload to disk or cloud storage without holding it in memory. Streamed uploads have the same properties and methods as `FileUpload`, but their contents can only be read once, `size` throws until they have been read, `slice()` is not supported, and they are not `File` instances. Returning the upload itself from the handler stores it in memory like an ordinary `FileUpload`.
