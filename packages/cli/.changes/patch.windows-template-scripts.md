New apps created with `remix new` on Windows now run `dev`, `hmr`, `start`, and `test` through `cross-env-shell`, avoiding the `'NODE_ENV' is not recognized` error in Windows command shells while preserving Ctrl+C shutdown handling. The generated app includes `cross-env` as a production dependency so `start` also works when development dependencies are omitted. Apps created on macOS and Linux keep their existing scripts and dependencies (see #11996).
