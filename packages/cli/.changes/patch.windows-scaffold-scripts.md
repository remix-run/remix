Generate cross-platform npm scripts in new projects so they run on Windows

The scaffolded `package.json` previously set `NODE_ENV` with a POSIX-only `NODE_ENV=value ...` prefix. npm runs scripts through `cmd.exe` on Windows, which treats that prefix as a command and fails with `'NODE_ENV' is not recognized`. The `dev`, `hmr`, `start`, and `test` scripts now force their mode from inside small entry scripts (`dev.ts`, `hmr.ts`, `start.ts`, `test.ts`) by assigning `process.env.NODE_ENV`, so each script behaves the same on every platform and an inherited `NODE_ENV` (for example `production` set by CI) no longer overrides it.
